***Originally published on December 8, 2025, updated on December 10, 2025***

We are announcing that DangoPlayer support for Android 5.x Lollipop has reached End of Life (EOL), which means that DangoPlayer is no longer supported on Android 5.x Lollipop since version 26.4 "Elio" Servicing Release 4

<!--more-->

## Why DangoPlayer is no longer supported on Android 5.x Lollipop?

The reason of why support for Android 5.x Lollipop has been removed from DangoPlayer is because Google's AndroidX Media3 library (which powers DangoPlayer) would require at least API Level 23 (Android 6.0 Marshmallow) since version 1.9.0, as seen on <a href="https://github.com/androidx/media/releases/tag/1.9.0-alpha01">1.9.0-alpha01</a>, which means that support for Android 5.x Lollipop has been removed from DangoPlayer since versión 26.4 "Elio" Servicing Release 4 as migrated to AndroidX Media3 <a href="https://github.com/androidx/media/releases/tag/1.9.0-rc01">1.9.0-rc01</a>

Also, Google ended support for Google Play Services on Android 5.x Lollipop on July 11, 2024

## What is the future of DangoPlayer, and how users of Android 5.x Lollipop devices will be affected?

The newest update of DangoPlayer is DangoPlayer 26.4 "Elio" Servicing Release 4, which updated AndroidX Media3 to version <a href="https://github.com/androidx/media/releases/tag/1.9.0-rc01">1.9.0-rc01</a>, consequently dropping support for Android 5.x Lollipop, this makes DangoPlayer 26.3 "Elio" Servicing Release 3 the last version of DangoPlayer to support Android 5.x Lollipop 

The next major version of DangoPlayer would be DangoPlayer 27 "Unimarutchi", which is planned to be released on July 7, 2026, coinciding with the 3rd anniversary of the modern DangoPlayer app (initially known as DangoPlayer Uni), which was released on July 7, 2023

The way DangoPlayer users on Android 5.x Lollipop devices will be affected is that they will no longer receive new DangoPlayer updates beyond 26.3 "Elio" Servicing Release 3
